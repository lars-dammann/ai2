# Analysis and Code of "Corrosion Beneath the Crust: Determination of Concealed Volume Loss from Optical Corrosion Imprints by Quantitative Imaging"

This repository contains the code of a U-Net-based regression model to quantitatively determine concealed corrosion volume loss directly from images of corrosion samples. Specifically, the model predicts pixel-resolved corrosion depth from the optical appearance of product-covered imprints, effectively recovering subsurface information masked by corrosion products. This approach enables accurate estimation of corrosion volume loss and inhibition efficiency without prior removal of corrosion products, providing a faster, safer and more scalable workflow for high-throughput corrosion modulator screening.

For more information see the original paper [*Corrosion Beneath the Crust: Determination of Concealed Volume Loss from Optical Corrosion Imprints by Quantitative Imaging*]().

## Project structure

The project contains three directories of importance:
- [`preprocess`](./preprocess): Contains the notebooks and scripts used to preprocess the image data, making it applicaple for training of the U-Net. The data was generated by [*C. Song et al*.](https://doi.org/10.1016/j.corsci.2025.112903). A description of the preprocessing procedure is provided in the SI of the mentioned paper as well as in [`preprocess/PREPROCESSING.md`](./preprocess/PREPROCESSING.md)

- [`ai2`](./ai2): Contains the code for the presented regression model.
    - [`ai2/crossvaldiation.py`](./ai2/crossvaldiation.py): Trains the model for every crossvalidation training fold.
    - [`ai2/predict.py`](./ai2/predict.py): Generates predictions from the trained models on every crossvaldation test fold.
    - [`ai2/tune.py`](./ai2/tune.py): Hyperparamter optimization of the model.
    - [`ai2/datamodule`](./ai2/datamodule): Code that defines the torch datamodules and dataloaders.
    - [`ai2/model`](./ai2/model): Definition of the PytorchLightning regresssion model.
    - [`ai2/utils`](./ai2/utils): Defines helper classed, e.g. to split the data into crossvaldiation folds, data loading and normalization.

- [`configs`](./configs): Contains the datamodule, U-Net and trainer configurations.

- [`results`](./results): Evaluation notebook and results of the trained models and code to generate figures used in the paper.
